## About

PatchWork is a desktop workstation and node-based visual workflow automation engine for generative media (video, image, voice, and audio).

- **Multi-Model Canvas**: Chain and orchestrate generation models seamlessly.
- **Integrated Video Editor**: Cut, trim, rearrange, and composite generative takes directly on the timeline.
- **Local & Cloud Hardware**: Connect to local ComfyUI instances or cloud GPU providers.
